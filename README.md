# Voxly Releases

Public release distribution for Voxly.

This repository hosts downloadable Voxly application releases. Application source code remains in the private Voxly repositories.

## Android

Download the latest Android release from the [Releases page](https://github.com/finalcircuitgame-crypto/Voxly-Releases/releases).

Each Android release should include:
- The signed APK
- Version number and release notes
- SHA-256 checksum
